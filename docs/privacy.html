SuperCube 隐私政策

生效日期：2026-07-19

本隐私政策适用于 SuperCube iOS App 以及 App 内加载的 SuperCube 网页游戏内容。

1. 我们收集什么

当前版本的 SuperCube 不要求注册账号，不接入广告 SDK，不接入第三方统计 SDK，不请求相机、麦克风、通讯录、照片、定位等系统权限。

SuperCube 当前通过 WKWebView 加载线上游戏页面 https://super-cube-rho.vercel.app。为了让页面正常交付，网页托管、内容分发和安全服务可能会处理必要的技术信息，例如 IP 地址、设备浏览器请求信息、访问时间、请求 URL、网络错误和安全日志。这些信息仅用于页面交付、安全防护、排障和稳定性维护，不用于跨 App 或跨网站追踪，也不会出售给第三方。

游戏进度、设置、教学进度和类似信息如有保存，通常保存在设备本地的浏览器存储中。卸载 App 或清除网站数据可能会删除这些本地数据。

2. 我们如何使用信息

  • 加载和展示 SuperCube 游戏内容；
  • 保持 App 与网页服务稳定；
  • 排查崩溃、加载失败、弱网或兼容性问题；
  • 防止滥用、异常访问和安全风险；
  • 在未来联网对战上线后，支持匹配、房间同步和对战状态传输。

3. 联网对战相关说明

SuperCube 的长期方向包含联网对战。联网对战正式启用前，本政策会再次更新。联网对战可能需要处理房间 ID、连接状态、对战同步消息、协议版本、错误日志和基础匹配信息。这些信息将只用于完成实时对战、反作弊、安全和排障，不会用于广告追踪。

4. 第三方服务

  • 网页托管与内容分发服务：用于提供 App 内加载的游戏网页；
  • Apple 系统服务：用于安装、运行、TestFlight 测试和 App Store 分发。

如果未来接入新的统计、登录、支付、广告、服务器监控或客服服务，我们会在本政策中说明。

5. 儿童隐私

SuperCube 当前不是专门面向 13 岁以下儿童的产品。我们不会故意收集儿童的个人信息。如果你认为我们意外处理了儿童个人信息，请联系我们，我们会尽快处理。

6. 数据保留

设备本地数据保留在用户设备中，直到用户删除 App、清除网站数据，或游戏自身提供的清除机制生效。

服务器或托管服务产生的技术日志会按照服务提供方的安全和运维策略保留，并在不再需要时删除或匿名化。

7. 用户选择

  • 删除 App，以移除 App 本体和部分本地数据；
  • 在系统设置中清除网站数据，以移除 WKWebView 相关本地存储；
  • 如需提出隐私相关问题或删除请求，可通过下方联系方式联系我们。

当前版本没有账号系统，因此暂不提供独立的账号删除入口。

8. 政策更新

当 SuperCube 增加联网对战、账号、云存档、统计、付费或其他新功能时，本政策可能更新。更新后的政策会在公开页面或 App 说明中展示新的生效日期。

9. 联系方式

如对隐私政策或数据处理有疑问，请通过 GitHub 项目页面联系开发者：

https://github.com/Pluto-Li-1990/SuperCube/issues

SuperCube Privacy Policy

Effective date: July 19, 2026

This Privacy Policy applies to the SuperCube iOS app and the SuperCube web game content loaded inside the app.

1. What We Collect

The current version of SuperCube does not require an account, does not include advertising SDKs, does not include third-party analytics SDKs, and does not request system permissions such as camera, microphone, contacts, photos, or location.

SuperCube currently loads the web game at https://super-cube-rho.vercel.app inside a WKWebView. To deliver the page, web hosting, content delivery, and security services may process necessary technical information such as IP address, browser request information, access time, requested URL, network errors, and security logs. This information is used only for content delivery, security, troubleshooting, and service reliability. It is not used to track users across apps or websites, and it is not sold to third parties.

Game progress, settings, tutorial progress, and similar information, when saved, are generally stored locally on the device through browser storage. Uninstalling the app or clearing website data may remove this local data.

2. How We Use Information

  • load and display SuperCube game content;
  • keep the app and web service stable;
  • troubleshoot crashes, loading failures, network issues, and compatibility problems;
  • prevent abuse, abnormal access, and security risks;
  • support matchmaking, room synchronization, and battle state transfer when online multiplayer is enabled in the future.

3. Online Multiplayer Notice

SuperCube is intended to support online multiplayer in the future. This policy will be updated again before online multiplayer is publicly enabled. Online multiplayer may require room IDs, connection state, synchronized match messages, protocol versions, error logs, and basic matchmaking information. These will be used only for real-time gameplay, anti-abuse, security, and troubleshooting, not for advertising tracking.

4. Third-Party Services

  • web hosting and content delivery services, to provide the game page loaded inside the app;
  • Apple system services, for installation, runtime, TestFlight testing, and App Store distribution.

If we add analytics, login, payment, advertising, server monitoring, customer support, or similar services in the future, we will update this policy.

5. Children's Privacy

SuperCube is not currently directed specifically to children under 13. We do not knowingly collect personal information from children. If you believe that we have accidentally processed a child's personal information, please contact us so we can address it.

6. Data Retention

Local data remains on the user's device until the user deletes the app, clears website data, or uses any in-game clearing mechanism that may be provided.

Technical logs generated by hosting or server services are retained according to the relevant provider's security and operations policies, and are deleted or anonymized when no longer needed.

7. Your Choices

  • delete the app to remove the app and part of its local data;
  • clear website data in system settings to remove WKWebView-related local storage;
  • contact us using the information below for privacy questions or deletion requests.

The current version does not include an account system, so there is no separate account deletion flow.

8. Changes

We may update this policy when SuperCube adds online multiplayer, accounts, cloud saves, analytics, payments, or other new features. The updated policy will show a new effective date.

9. Contact

For questions about this policy or data handling, please contact the developer through the GitHub project page:

https://github.com/Pluto-Li-1990/SuperCube/issues
