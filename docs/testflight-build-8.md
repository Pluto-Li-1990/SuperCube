# SuperCube TestFlight Build 8 测试说明

## 本次重点

Build 8 主要用于验证上线前的联网版体验：

- 实机启动稳定性：确认 App 可正常进入大厅，不再出现黑屏或长时间加载。
- 在线对战：进入“在线对战”后可连接 `wss://match.supercubegame.com`，两台设备可匹配、落子、同步回合并结算。
- 账号入口：可使用游客身份继续；支持 Apple 登录入口，账号信息保存在本机并用于在线对战昵称。
- 源力工坊：编辑中的棋子退出后再次进入不会丢失；铸造入库的棋子可在陈列滚轴中看到缩略图并可删除。
- 天气反馈：雨、雪、雷暴、火山触发棋盘变化时，会出现棋盘高亮、文字日志和短音效提示。
- 音效/BGM：确认音效可开关，BGM 风格已改为更轻松的拨弦循环。

## 建议测试流程

1. 首次打开 App，确认启动页能进入大厅。
2. 完成一次“对战 vs AI”，观察基础落子、消除、天气变化和音效。
3. 进入“源力工坊”，编辑一个自定义棋子，返回大厅再进入工坊，确认草稿保留。
4. 将棋子铸造入库，确认陈列滚轴显示缩略图；再删除一次确认状态刷新。
5. 两台设备同时进入“在线对战”，确认可匹配、双方落子同步、对局结束能回到大厅。
6. 在系统设置里分别关闭/开启音效和 BGM，确认设置生效。

## 需要反馈的信息

如果遇到问题，请记录：

- 设备型号和 iOS 版本。
- 使用的是 Wi-Fi 还是蜂窝网络。
- 是否在首次启动、进入大厅、进入工坊、在线匹配或对战中发生。
- 是否出现“重新加载”按钮或其它错误提示。
- 问题发生前最后一步操作。
